📖 Detailed Step-by-Step User Guide

Step 1: Load Your Photo (Drag & Drop or Ctrl+V) · [Dropzone (#dz) or Clipboard Paste]Open Photo Privacy Kit and drag one or more JPEG, PNG, or WebP images onto the main dropzone (`#dz`), click to browse your device, or press `Ctrl+V` (`Cmd+V` on Mac) to paste directly from your clipboard.✓ Result: The file loads immediately into browser memory with zero network activity.
Step 2: Inspect the Live Metadata & GPS Leak Report · [Leak Report Table (#list)]Read the per-file inspection row under `#list`. Red warning badges highlight high-risk leaks such as exact GPS latitude/longitude coordinates, device make/model, capture timestamps, and embedded EXIF thumbnails.✓ Result: Every detected EXIF, XMP, IPTC, and comment segment is listed byte-by-byte.
Step 3: Strip Metadata & Toggle SHA-256 Pixel Proof · [Strip Button (#strip) & SHA-256 Toggle]Optionally toggle **Show SHA-256 fingerprints** to display the decoded RGBA pixel hash before and after cleaning. Click **Strip metadata & download all (`#strip`)** (or **Download as .zip** for batches).✓ Result: The segment parser strips APP1/APP13/XMP/COM markers without re-encoding your pixels.
Step 4: Verify GPS CLEAR & Save Cleaned Image · [Verified Output Row (GPS CLEAR)]Verify that the status badge turns green (**GPS CLEAR — 0 metadata segments**) and that the before/after decoded pixel SHA-256 hashes match 100%.✓ Result: Cleaned `.clean.jpg` / `.png` / `.webp` saved locally with zero generation loss.

🎛️ UI Controls & Shortcuts Reference

  • Dropzone (`#dz`) / `Ctrl+V` — Accepts single or batch `.jpg`, `.jpeg`, `.png`, and `.webp` files via drag-and-drop, file picker, or clipboard paste.
  • Strip metadata & download all (`#strip`) — Removes EXIF, GPS, XMP, IPTC, and comment segments from every loaded file and downloads cleaned copies.
  • Download as .zip (`#zip`) — Bundles all cleaned images into a single local `.zip` archive when processing multiple photos.
  • Show SHA-256 fingerprints (`#shaToggle`) — Computes the SHA-256 digest of the decoded pixel buffer before and after stripping to prove zero pixel alteration.

💡 Pro Tips & Real-World Workflows

  • Press `Ctrl+V` right after taking a system screenshot to strip OS color-profile and timestamp chunks before sharing on Slack, Discord, or GitHub issues.
  • Because Photo Privacy Kit strips container markers at the byte level without re-compressing JPEG blocks, your photo never suffers JPEG generation loss.
  • Drop a cleaned `.clean.jpg` file back into the dropzone at any time to confirm it reports `0 metadata segments`.
